# v2.2.0 Release Notes

## Changes

- Added Garmin China support through `--domain cn` and `GARMIN_DOMAIN`. The CLI saves the selected domain with the credentials.
- Existing commands and credentials continue to use `garmin.com` by default. A saved China profile keeps its selected domain.
- Added worker progress during sync.
- Improved sync task claims and recovery from stale claims.
- Optional empty health responses now count as unavailable data. The HRV command also handles unavailable data.

## Validation

- The merged code passed all 184 local tests, formatting, and Clippy with warnings denied on macOS ARM64.
- Live China authentication was not independently verified.
